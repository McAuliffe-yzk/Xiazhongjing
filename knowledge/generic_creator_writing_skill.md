# 匣中镜通用创作者基线 Skill v2.2

## 适用范围

这是空白安装时使用的通用创作基线。它只保证事实、叙事与口语表达的基本质量，不声称已经像某位具体创作者。用户完成历史文稿蒸馏并发布个人 Skill 后，个人版本将完整覆盖本基线。

## 规则优先级

1. 当前稿、当前素材、锁定原句与用户明确指令。
2. 字数、表达边界和叙事模式等硬参数。
3. 已发布的个人 DNA；空白安装时才使用本基线。
4. 抖音节奏、书库引文等可选增强。

## 核心创作原则

- 每篇只围绕一个核心问题或主题推进。
- 先写真实事件，再让判断从事件中长出来。
- 抽象词必须由当前素材中的场景、动作、对话或事件托住。
- 允许犹豫、自我追问和判断修正，不写成站在终点说教。
- 长句推进思绪，短句承担停顿和落点，保持可朗读节奏。
- 结尾回到主题，但不总结全文，不使用空泛祝福或成功口号。
- 历史文稿只提供表达方法，不提供可迁移事实。
- 不新增素材里没有的人物、地点、日期、对话、结果或感官细节。

## 素材表达边界

- **原句**：逐字保留，只调整位置和前后衔接。
- **改写（默认）**：保留事实与含义，重建句法、观察角度和叙事关系。
- **阐释**：完整保留原句，再用当前素材中的事件、对照或当下判断展开。

## 叙事模式

### 默认模式

根据素材自由组合“进入、事件、自我修正、洞察、回扣”。段落数不固定，但洞察必须有事件依据。

### 排比递进式

使用三至五个层级不断变化的事件或判断推进主题，随后用一个具体落点收回。禁止同义反复。

### 六段式

按“引入、发展、高潮、沉淀、回扣、升华”承担六种叙事作用，正文不得输出阶段标题。升华只多想一步，不拔高成口号。

### 先抑后扬式

前段保留真实困顿，后段变化必须由当前素材中的行动、事件或重新理解触发，不突然转为正能量宣言。

## 新写与改写

### 新写

素材是事实边界和创作原料，不是等待串联的原句列表。生成前先确认主题、事实、必须保留文本与收束方向，再重新组织表达。

### 重写当前稿

编辑器当前稿是唯一内容来源。保留其中事实、人物、日期、对话、立场与意象，只优化段落作用、叙事关系、句法、口语节奏和收束。不回看项目原始素材，不做逐句同义替换。

## 字数策略

- 手动字数是硬约束，应在目标值附近完成完整叙事，不依靠生成后的机械截断。
- 自动字数根据信息密度决定；素材少时不凑字，素材多时优先保留关键事件、转念和回扣。
- 压缩时先删重复解释和不推进主题的句子，扩展时只能发展已有事实之间的关系。

## 书库引文

- 只使用请求中提供且已核验的直接引文。
- 引文应落在转念、对照、高潮后的冷静或主题回扣位置。
- 不以“想到某书时”“某书告诉我们”等书评式句子强行介绍。
- 没有合适时机就不使用，不把转述包装成原文。

## 生成后检查

1. 是否只使用了当前输入中的事实。
2. 是否有一个明确主题，且事件都在推动它。
3. 是否出现真正的情绪变化或认知修正。
4. 是否避免流水账、概念定义、AI 过渡词和空洞画面。
5. 是否符合表达边界、叙事模式与字数约束。
6. 结尾是否留下姿态、动作、意象或反问，而非摘要和祝福。
