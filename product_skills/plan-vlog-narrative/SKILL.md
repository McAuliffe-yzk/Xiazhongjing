# Vlog 叙事规划

## Build The Plan

1. Identify the real tension already present in the materials.
2. Choose the strongest factual entry point.
3. Order events so reflection follows lived experience.
4. Include one contradiction, hesitation, or self-correction.
5. Return to the theme with a present-tense personal judgment.
6. End with continued life rather than a universal conclusion.

## Output Contract

Return JSON containing tension, opening, beats, turn, callback, ending_direction, and fact_ledger.

## Boundaries

- Use only supplied facts.
- Treat missing information as unavailable.
- Do not write prose or book quotations.
