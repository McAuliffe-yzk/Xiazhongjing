# 书库金句植入 Skill

## 任务边界

输入是一份已经完成的 Vlog 文案、项目素材、叙事架构和本地书库候选。候选由用户提供的阅读笔记或本地书籍资料沉淀而来。DeepSeek 只负责判断契合度、选择候选和安排位置，不负责创造候选文本。

## 执行规则

1. 只能从候选列表中选择，`quote` 必须与候选原文完全一致；不得凭模型记忆补写，不得改写、拼接或翻译。
2. 只允许 `exact_quote`，禁止 `thought_transfer`、思想转译、解释性替代和无来源金句。
3. 植入数量由本次金句策略决定：克制目标 1 条、标准目标 2 条、增强目标 3 条；任何策略最多 3 条。标准/增强策略要优先找满目标数量，只有完整文案确实没有足够自然转念位置时，才允许少于目标并说明原因。没有自然位置时返回原文和空 `supports`。
4. 优先放在真实转念、判断或回扣之前，不在开头做装饰性引用，也不为了覆盖所有书籍而强行植入。
5. 先判断时机：高潮后的判词、思考下沉时的支点、回引/升华前的暗扣，只有时机成立才植入；多条引文必须承担不同叙事功能，不能堆在同一段。
6. 引文必须服务于创作者的第一人称叙事，不能取代个人事件、日常细节和最终判断。
6. 允许使用以下自然句式：
   - `《XXX》里有这样一句话：“原文”`
   - `“原文”（《XXX》）`
   - `作者/人物在《XXX》中写道：“原文”`，仅当候选提供了可靠 attribution 时使用。
7. 不得使用“想到《XXX》时，我更愿意把它理解成……”等转述式句型。

## 输出契约

```json
{
  "updated_copy": "植入后的完整文案；没有合适位置时返回原文",
  "supports": [
    {
      "mode": "exact_quote",
      "candidate_index": 0,
      "book": "《道德经》",
      "quote": "与候选逐字一致的原文",
      "text": "文中的完整连接句或上下文",
      "attribution": "作者或人物",
      "source_url": "local-note://...",
      "source_title": "本地阅读笔记文件名",
      "reason": "为什么正好适合这个叙事时机",
      "location": "高潮后判词/思考下沉支点/回引或升华前暗扣"
    }
  ]
}
```

## 失败边界

候选为空、引文不在候选中、引文在成稿中不完整、书名缺失或返回了非 `exact_quote` 模式时，返回原文、空 `supports` 和可解释原因。不得用转述或兜底句填补空位。
