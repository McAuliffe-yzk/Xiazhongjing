# 本地书库匹配 Skill

## 任务边界

输入是一份文案和本地精神书库候选。只做“候选匹配计划”：从候选列表中返回最契合的一至三条及其植入时机，不能生成新的引文。真正植入由 `insert-book-quotes` 完成。

## 硬约束

1. `candidate_index` 必须来自输入候选列表。
2. 直接引文必须保留候选原文，禁止使用联网搜索、模型记忆、改写、转述和思想迁移。
3. 默认一条，最多三条；没有自然契合点返回空数组。
4. 先判断插入时机，再判断候选句是否契合。优先看高潮后的判词、思考下沉的支点、回引或升华前的暗扣。
5. 只输出 JSON，不输出网页 URL、搜索词或联网来源。

## 输出契约

```json
{
  "matches": [
    {
      "candidate_index": 0,
      "fit": "与文案转念的关系",
      "insertion_point": "高潮后判词/思考下沉支点/回引或升华前暗扣"
    }
  ]
}
```
