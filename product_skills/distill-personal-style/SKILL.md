# 个人风格蒸馏

## Workflow

1. Analyze the uploaded draft independently before reading existing style rules.
2. Extract evidence for narrative structure, sentence rhythm, emotional movement, openings, endings, recurring transitions, and prohibited generic patterns.
3. Separate stable patterns from one-off subject matter. Do not promote names, events, places, or isolated phrases into reusable style rules.
4. Compare the evidence with the published style and produce a complete candidate style, not append-only notes.
5. Return evaluation evidence and wait for explicit publication.

## Input

Require the filename, full extracted text, published style, and prior evidence summary.

## Output

Return structured analysis plus a complete candidate writing skill. Include supported rules, conflicts, confidence, and evaluation notes.

## Hard Rules

- Never copy historical events into future projects.
- Never infer a stable preference from one isolated sentence.
- Never publish automatically.
- Fail when the source is too short or the model output is incomplete.
