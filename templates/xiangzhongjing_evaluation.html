01 / POSITION

产品定位不是“AI 写作”

一个只会生成文案的工具没有护城河；一个能持续学会个人表达的创作系统才有。

当前最强价值

个人创作 DNA 的可执行化

历史文稿不再只是被召回的片段，而是被沉淀为可版本化的写作 Skill，与真实素材、书库和编辑行为共同形成个人创作系统。

现阶段不是什么
  • 不是通用文案生成器
  • 不是多平台内容运营中台
  • 不是创作者数字分身平台
  • 不是视频拍摄与剪辑工具
北极星指标 30 分钟内产出可发布稿件的项目比例

这个指标同时约束风格质量、生成速度、交互成本和稳定性。

02 / FOUR DIMENSIONS

四维深度评估

评分衡量“当前阶段是否支撑真实高频使用”，不衡量功能数量。

A

用户体验与交互

核心闭环与移动导航已经成立，生成任务的可控性仍是主要断点。

7.0

已成立

  • 项目到发布的完整链路
  • 移动端为 4 个核心入口 + 更多
  • “发布到日记”的动作语义明确
  • 保存串行化且冲突可感知

关键断点

  • P0 生成任务仍缺少用户取消
  • P0 生成失败率尚未用新基线重测
  • P1 对话资产对发稿的帮助尚未证明
  • P1 移动端需持续做固定回归

迭代动作

  • 优先完成 3-5 个真实项目
  • 增加取消与定向重试
  • 记录重生成、编辑距离与发布耗时
  • 维持桌面/移动核心链路回归
B

UI 视觉与设计美学

品牌气质与工作密度开始统一，核心操作的视觉一致性明显提升。

7.5

已成立

  • 宣纸、墨色、玉绿和朱红形成品牌识别
  • 编辑器、书库和日记本隐喻统一
  • 圆角、阴影与卡片层级基本克制

关键断点

  • P1 少数旧组件仍有独立样式逻辑
  • P1 部分辅助文字需持续核对对比度
  • P1 空状态与稠密工作态的节奏尚未完全统一

迭代动作

  • 将 8 px 间距与 44 px 触控纳入回归
  • 继续清理旧组件的局部覆盖
  • 固定 1440 px 与 390 px 视觉验收
  • 保留水墨 DNA 品牌，不做视觉换肤
C

功能价值与信息呈现

核心差异化有价值，但当前仍用功能状态代替了用户结果。

7.3

已成立

  • 写作 Skill 而非旧稿片段拼接
  • “原句/改写/阐释”建立明确表达边界
  • 书库引用已进入生成主链
  • 风格版本与发布日记具备长期复利

关键断点

  • P0 没有首稿采用率与编辑距离

  • P1 对话功能尚未证明对发稿贡献

迭代动作

  • 建立“采用/小改/重写/放弃”反馈闭环
  • 将 92 条规则压缩为 DNA 核心与场景策略
  • 建立 20-30 个固定回归题目
  • 以对话资产复用率决定探索功能投入
D

代码架构与技术框架

已从单文件 Demo 进入模块化单体，保留本地单人产品的低运维成本。

7.4

已成立

  • `main.py` 缩减为 52 行应用组装
  • 6 个 API 边界 + 3 个应用服务
  • 8 个 JS 与 10 个 CSS 模块
  • 98 项测试 + Pydantic 核心契约

剩余风险

  • P1 DeepSeek 兼容引擎仍然较大
  • P1 全局 JSON 已有 revision，但未完全结构化
  • P1 生成请求断开后的底层取消尚需完善
  • P2 缺少持续视觉回归

迭代动作

  • 按生成、编辑、蒸馏逐步内聚 AI 引擎
  • 仅在真实数据增长时拆分状态表
  • 建立可取消的生成任务语义
  • 不引入 React、微服务或队列

FINAL DECISION

先证明“像我”，再证明“像每一个人”。

匣中镜当前最有价值的路线，是继续服务真实的创作者本人创作流程，先用接下来 3-5 个项目建立无负担质量基线。v2.1 稳定版始终保留，v2.2 只在证据明确且人工审核后才可发布。
